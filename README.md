# Código Divino — página de vendas

Página estática pronta para GitHub Pages.

## Como publicar

1. Crie um repositório público no GitHub.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/root`, e salve.

Todos os botões de compra apontam para `https://pay.kiwify.com/2CLHYRi`.
